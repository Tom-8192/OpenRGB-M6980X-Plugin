First release of the **OpenRGB 1.0 plugin** for the **Gigabyte GHOST M6980X** mouse (USB `E0FF:0001`). It
adds the mouse to OpenRGB with its per-profile LED colours.

### Downloads

| File | Contents |
|---|---|
| `OpenRGB-M6980X-1.0.0-windows-x64.zip` | `OpenRGB-M6980X.dll` for the official OpenRGB 1.0 Windows 64-bit build (Qt 6.8.3, MSVC 2022) |
| `OpenRGB-M6980X-1.0.0-linux-x64-qt6.tar.gz` | `libOpenRGB-M6980X.so` (built on Ubuntu 24.04, Qt 6.4), udev rule `60-openrgb-m6980x.rules` |

### Installation

- **Windows:** copy `OpenRGB-M6980X.dll` to `%APPDATA%\OpenRGB\plugins\` and restart OpenRGB. If OpenRGB runs as a
  Windows service, put the plugin into the GUI (the folder above), not into the service: the GUI connects to the
  service and runs the plugin itself.
- **Linux:** copy `libOpenRGB-M6980X.so` to `~/.config/OpenRGB/plugins/` and install the udev rule (see README).
  Needs an OpenRGB built with Qt 6.4 or newer; AppImages bring their own Qt. If it does not load, build the plugin
  against your OpenRGB's Qt (see README).

### Features

- **Two modes**, chosen in the device view, remembered across restarts:
  - **Per profile** (default): three LEDs *Profile 1–3* set the colour of each hardware profile directly. Written
    once a colour stayed unchanged for a second; switching profiles writes nothing.
  - **Static**: one colour; applying it (also with quick colours) writes it once into the active profile. After a
    switch with the profile button OpenRGB shows that profile's colour; nothing is written.
- Colours are rounded to the mouse's 3 levels per channel (27 colours) and only written when they differ from what
  the mouse has. No direct/effects mode: the mouse stores every colour change permanently.
- Starting OpenRGB or switching the mode never changes the mouse.
- Unplugging and replugging is detected.
- Runs alongside the M6980X Configuration Tool (shared lock).
- Status page under *Settings → M6980X*, log messages with the prefix `[M6980X]`.

### Tested

Windows 10 with the official OpenRGB 1.0 on the real mouse, including the OpenRGB GUI as client of the OpenRGB
Windows service. Linux: built and unit-tested only, not yet tried on the mouse.
