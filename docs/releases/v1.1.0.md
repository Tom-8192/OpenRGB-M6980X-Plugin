**OpenRGB profile support** for the Gigabyte GHOST M6980X plugin.

### Downloads

| File | Contents |
|---|---|
| `OpenRGB-M6980X-1.1.0-windows-x64.zip` | `OpenRGB-M6980X.dll` for the official OpenRGB 1.0 Windows 64-bit build (Qt 6.8.3, MSVC 2022) |
| `OpenRGB-M6980X-1.1.0-linux-x64-qt6.tar.gz` | `libOpenRGB-M6980X.so` (built on Ubuntu 24.04, Qt 6.4), udev rule `60-openrgb-m6980x.rules` |

Installation as for 1.0.0: replace the plugin file (close OpenRGB first) and restart OpenRGB. See the README.

### New

- **OpenRGB profiles** now include the M6980X: saving a profile stores the mode (*Per profile* / *Static*), the
  static colour and the three profile colours in the plugin section of the profile. Loading it applies them like a
  manual change (Static: once into the active hardware profile); only colours that differ from the mouse are
  written.
- Works with the OpenRGB GUI as client of the OpenRGB service, where the server would not restore the plugin's
  device itself.
- A profile loaded before the mouse is plugged in is applied once it connects.
