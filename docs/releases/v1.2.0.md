**OpenRGB 1.1** build of the Gigabyte GHOST M6980X plugin.

### Downloads

| File | Contents |
|---|---|
| `OpenRGB-M6980X-1.2.0-windows-x64.zip` | `OpenRGB-M6980X.dll` for the official OpenRGB 1.1 Windows 64-bit build (Qt 6.8.3, MSVC 2022) |
| `OpenRGB-M6980X-1.2.0-linux-x64-qt6.tar.gz` | `libOpenRGB-M6980X.so` (built on Ubuntu 24.04, Qt 6.4), udev rule `60-openrgb-m6980x.rules` |

Installation as before: replace the plugin file (close OpenRGB first) and restart OpenRGB. See the README.

### Changes

- Built against OpenRGB **1.1** (`release_1.1`) instead of 1.0. The plugin API (version 5) and the interfaces the
  plugin uses are unchanged, so the plugin code itself is the same as in 1.1.0. Use 1.1.0 if you stay on
  OpenRGB 1.0.
- New in OpenRGB 1.1: when the GUI starts while an OpenRGB profile is active (for example the service's startup
  profile), OpenRGB passes that profile's plugin data to the plugin, which applies it like loading the profile.
  As before, only colours that differ from the mouse are written.
