**Simpler device view** for the Gigabyte GHOST M6980X plugin.

### Downloads

| File | Contents |
|---|---|
| `OpenRGB-M6980X-1.3.0-windows-x64.zip` | `OpenRGB-M6980X.dll` for the official OpenRGB 1.1 Windows 64-bit build (Qt 6.8.3, MSVC 2022) |
| `OpenRGB-M6980X-1.3.0-linux-x64-qt6.tar.gz` | `libOpenRGB-M6980X.so` (built on Ubuntu 24.04, Qt 6.4), udev rule `60-openrgb-m6980x.rules` |

Installation as before: replace the plugin file (close OpenRGB first) and restart OpenRGB. See the README.

### Changes

- **One mode** (*Profile colours*) instead of *Per profile* and *Static*, so there is nothing to choose.
- **One zone per hardware profile** (*Profile 1–3*): the zone list picks the profile, **All zones** applies a
  colour to all three profiles (quick colours do the same). The LED list stays because it is part of OpenRGB's
  device view, but it is not needed.
- OpenRGB profiles saved in the former *Static* mode still work: their colour goes into the active profile only.
- The plugin no longer stores a mode in the OpenRGB settings (`M6980XPlugin` key; an existing entry is ignored).
- The plugin description changed, so OpenRGB adds a new entry to its plugin list; the old one can be removed.

Quick colours set all three profiles, so profiles that should keep different colours (for example to tell button
mappings apart) are best set through the zones.

Not yet tried on the mouse: applying a colour from the GUI to a single zone (start, profile loading, profile
switches, quick colours and *All zones* were tested).
